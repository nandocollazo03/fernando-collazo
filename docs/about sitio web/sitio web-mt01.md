# Sobre el sitio web

Este sitio utiliza como punto de partida un Fork del efdi-template (un template para el repositorio personal de los estudiantes durante la Especialización en Fabricación Digital e Innovación (EFDI - UTEC & FAB LAB BARCELONA)).

Fue realizado con Material for MkDocs, un framework para MkDocs enfocado en la creación de documentación técnica que permite generar sitios web estáticos.

Cuenta con un diseño adaptable que se ajusta a teléfonos móviles, tabletas y ordenadores de escritorio.
